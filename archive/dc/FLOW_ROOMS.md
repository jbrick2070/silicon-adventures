# Flow prompts for the 24 standout rooms

Use these in Flow with **image input**. For each room:

1. Upload `art/es-3d/guides/ASCN-<id>.png`.
2. Paste the shared prompt, then the room line.
3. Use the square-ish shape closest to the upload.
4. Save the best result as `art/es-3d/incoming/ASCN-<id>.png`, keeping the number in the name.

Start with room 21149 only, so its result can be checked before you do the rest.

## Shared prompt

```text
Repaint this exact scene as a rich, truly lit 3D render. Keep the camera, horizon and perspective, and keep every wall edge, doorway, object and landmark exactly where it is in this image. Do not add, remove or move anything. No new text, people, frames or borders. Solid realistic materials, muted dark yellow key light from the upper left, cool slate fill, no orange, soft detail. Do not add a dark vignette.
```
