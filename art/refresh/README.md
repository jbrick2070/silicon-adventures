# Visual Refresh Layers

The image layers are derived from the Macintosh resource fork and decoded Dark Castle sprites. The rig tables and review evidence below are maintained separately. The original room plates (`archive/es/plates/*`), separated command layers (`art/*.png`, `art/foreground/*.png`), and sprite sheets (`art/castle-wizard.png`, `art/castle/*.png`) remain untouched and continue to pass `python art/verify_layers.py`.

## Contents

| Path | Role |
| --- | --- |
| `plates/ASCN-<id>.png` | Per-pixel `CODE 1` pattern-index and stroke-border layers for all 200 room plates (`338 × 314`, greyscale + binary alpha). |
| `altar-*.png`, `quarters-*.png`, `sanctum-*.png`, `court-*.png` | Separated foreground and background tone/border layers for the four multi-part architectural rooms, starting with the High Altar (`ASCN 7990`). |
| `foreground/<id>-*.png` | Separated foreground and clean-plate tone/border layers for the 18 additional `foreground.tsv` scenes. |
| `sprites/castle-wizard-rim.png` | Separate `384 × 138` (`48 × 46` cell) 1-pixel paper silhouette rim layer for the High Altar wizard (`PPCT 430`, `431`, `432`), matching Dark Castle's masked frames so gestures stay readable over dark dithered stone. |
| `sprites/B-PPCT-*-rim.png` | Separate 1-pixel paper silhouette rim layers at native frame dimensions for the Dark Castle cave bat (`300`) and Black Knight reels (`908`, `912`, `915`). |
| `sprites/es/<TYPE>-<id>-rim.png` | Exterior-only 1-pixel paper rims at native dimensions for the 91 native `ACHR` inhabitants and hand-sized `AOBJ` pickups whose outlines touch transparent pixels. Interior holes are left open. |
| `forms/<id>-<key>.png`, `forms/<id>-clean.png` | Five additional separated forms lifted from the room plates’ own pixels (`17888` dais steps and throne, `8807` trestle table, `18458` platform) with their clean plates; `forms/tone/` holds their pattern-index layers. Clean plus forms reassemble each plate bit-for-bit. |
| `sprites/banana/AOBJ-<id>.png`, `banana-index.js` | Banana-bent stand-ins for the 17 weapon sprites at native size, used only in refreshed mode (`art/build_bananas.py`). |
| `rigs.js` | Eighteen measured rigs generated by `art/measure_rigs.py --write`. Admission requires a confident reading and a drawn junction over 25 pixels from the class default. |
| `hand-rigs.js` | Seventy hand-authored refreshed-mode overrides. Values omitted from an entry inherit its environment box. These entries are maintained by hand. |
| `room-review.tsv` | Decisions for all 149 rooms that had used environment defaults, ordered by campaign trace frequency. |
| [Room review](review/README.md) | Native-size contact sheets, per-room checks, calibration results and outstanding limitations. |
| `environments.js` | Hand-checked environment (`chamber`, `cave`, `open`, `submerged`) for all 200 rooms, seeded by `art/classify_environments.py`. Rooms without a rig of their own take its box in refreshed mode; caves drop courses and cornices and open rooms share one fixed horizon. |
| `refresh-index.js` | Lookup tables mapping layer luminance values back to one-based `ScepterPatterns` indices (`1–29`) and border flags, plus sprite rim paths and the lifted-form index. |

## Colour study

The High Altar study uses the disk ink as a mask over a fixed doorway view. The lamp lights the existing stone faces. Blended aubergine follows the height of the walls, carrying violet through the horizontal joint into the upper slate. The selector also contains the earlier solid aubergine and slate finishes. Open the standalone HTML in a WebGL 2 browser to move the lamp.
