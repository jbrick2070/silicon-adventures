# Visual Refresh Layers

All files in `art/refresh/` are non-destructive refinement layers generated by `python art/build_refresh.py` from `archive/es/Scepters.rsrc` and the decoded Dark Castle sprite sheets. The original room plates (`archive/es/plates/*`), separated command layers (`art/*.png`, `art/foreground/*.png`), and sprite sheets (`art/castle-wizard.png`, `art/castle/*.png`) remain untouched and continue to pass `python art/verify_layers.py`.

## Contents

| Path | Role |
| --- | --- |
| `plates/ASCN-<id>.png` | Per-pixel `CODE 1` pattern-index and stroke-border layers for all 200 room plates (`338 × 314`, greyscale + binary alpha). |
| `altar-*.png`, `quarters-*.png`, `sanctum-*.png`, `court-*.png` | Separated foreground and background tone/border layers for the four multi-part architectural rooms, starting with the High Altar (`ASCN 7990`). |
| `foreground/<id>-*.png` | Separated foreground and clean-plate tone/border layers for the 18 additional `foreground.tsv` scenes. |
| `sprites/castle-wizard-rim.png` | Separate `384 × 138` (`48 × 46` cell) 1-pixel paper silhouette rim layer for the High Altar wizard (`PPCT 430`, `431`, `432`), matching Dark Castle's masked frames so gestures stay readable over dark dithered stone. |
| `sprites/B-PPCT-*-rim.png` | Separate 1-pixel paper silhouette rim layers at native frame dimensions for the Dark Castle cave bat (`300`) and Black Knight reels (`908`, `912`, `915`). |
| `sprites/es/<TYPE>-<id>-rim.png` | Exterior-only 1-pixel paper rims at native dimensions for the 91 native `ACHR` inhabitants and hand-sized `AOBJ` pickups whose outlines touch transparent pixels. Interior holes are left open. |
| `forms/<id>-<key>.png`, `forms/<id>-clean.png` | Five additional separated forms lifted from the room plates’ own pixels (`17888` dais steps and throne, `8807` trestle table, `18458` platform) with their clean plates; `forms/tone/` holds their pattern-index layers. Clean plus forms reassemble each plate bit-for-bit. |
| `refresh-index.js` | Lookup tables mapping layer luminance values back to one-based `ScepterPatterns` indices (`1–29`) and border flags, plus sprite rim paths and the lifted-form index. |
